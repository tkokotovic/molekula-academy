# Glossary

## Acronyms & Terms
- **IB** — International Baccalaureate
- **HL / SL** — Higher Level / Standard Level (IB Chemistry course tracks)
- **LMS** — Learning Management System
- **MRR** — Monthly recurring revenue
- **HR / EN** — Croatian / English (site languages)
- **MathJax / KaTeX** — formula rendering libraries needed for chemistry equations
